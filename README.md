# Hist-ria-infantil-com-IA
Gerador de Histórias Infantis com IA 🚀 Web app que cria contos infantis leves e divertidos usando a API do Groq (Llama 3.3). O usuário digita o tema e a IA gera a história personalizada com os personagens Ágata ou Gael. Desenvolvido com HTML5, CSS3 moderno (Dark Mode/UX Responsiva) e JavaScript Assíncrono (Fetch API).
